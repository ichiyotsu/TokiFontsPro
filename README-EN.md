This project is an upgraded and enhanced version of TokiFontsResource. We've made it much easier to find fonts, added previews and intros, and included step-by-step download and installation guides.

The docs are broken down into five sections: About, Tutorials, Guides, Fonts, and More. If you're looking for font downloads and other resources, just head straight to the Guides section!

# I. About
<img width="1416" height="330" alt="1" src="https://github.com/user-attachments/assets/fe038590-adfc-47c5-b1a4-90491011e536" />
TokiFonts is a spin-off project built on top of the Samsung OneUI 8+ font-changing tutorials. It serves as a handy repository where we regularly dump and store fonts for everyone to download and use. Want to help out? You’re more than welcome to bring your own fonts and join us to expand the library!

TokiFonts comes in two flavors: Pro and Social.

• Pro Version (Formerly "Resource"): Fully managed and run by ichiyotsu. This version focuses primarily on open-source fonts and includes detailed tutorials and source information. If you run into any issues, feel free to open an Issue anytime!

• Social Version: This is all about community contributions. We’ll review and organize community submissions periodically, and some of the best picks might even get curated into the Pro version.
> The Social version hasn't launched yet. Once it’s live, we’ll update the guidelines—anything that doesn't fit the rules might get removed.

# II. Tutorial
<img width="1413" height="327" alt="2" src="https://github.com/user-attachments/assets/8d7164ed-5da7-4bad-a4f2-a1ae0bc0d96b" />

If you don't want to root and just want a simple font change, please check out Tutorial 2-1 or 2-2.
> This method might not work on certain pages or apps (for example, WeChat Moments).

If you're looking to change fonts via temporary root, take a look at Tutorial 2-3.
> Rooting comes with risks, so proceed at your own discretion. Also, some devices may require a reboot for the fonts to take effect.


If you want a full permanent root, we don't provide tutorials for that here.
>  A full root will permanently trip Knox. This means features like Samsung Wallet and Secure Folder will stop working completely. Banking apps might also block you. We highly recommend NOT trying this on your primary daily driver.
